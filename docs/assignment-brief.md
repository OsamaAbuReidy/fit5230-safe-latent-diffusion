# Assignment alignment

This repository is designed for the FIT5230 Malicious AI assignment, Theme 2 (Text-to-Image), Light side.

## Requirements shaping the project

- A Light team must improve the security, robustness, or trustworthiness of the selected Text-to-Image technique, or develop a defence against an attack-focused paper.
- Milestone 1 requires the reference paper/code, a compelling rationale, a clear problem statement, an interactive challenge, and a team-owned Colab or GitHub version.
- Milestone 2 rewards a functional base code, technical depth, reproducibility, documentation, and engagement with other teams.
- Milestone 3 requires a complete, executable, well-narrated Colab with pre-rendered evidence, sound evaluation, dependency management, and no hard-coded environment paths.
