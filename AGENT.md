# FIT5230 Project Instructions

## Project
FIT5230 Malicious AI assignment.

Theme: Text-to-Image.
Side: Light.
Baseline: Safe Latent Diffusion.

## Working rules
- Preserve reproducibility.
- Do not change baseline code silently.
- Keep baseline and modified implementations separate.
- Every experimental change must be configurable.
- Log seeds, prompts, model versions, parameters, and outputs.
- Prefer small, testable changes over large rewrites.
- Never fabricate experimental results.
- Never overwrite previous experiment outputs.
- Explain major architectural changes before implementing them.
- Keep notebooks lightweight; reusable code belongs in src/.
- Update README.md when setup or execution steps change.

## Research workflow
1. Reproduce baseline.
2. Validate baseline outputs.
3. Implement modification separately.
4. Compare baseline vs modified system.
5. Record metrics and qualitative examples.
